# KB_Agent

사용자 정보를 바탕으로 보험 리스크와 보장 공백을 분석하고, 적합한 보험상품을 제안하는 대화형 AI 보험 설계 에이전트 MVP입니다.

## 프로젝트 개요

보험상품은 구조가 복잡하고 사용자가 자신의 위험과 보장 부족 영역을 직접 판단하기 어렵다는 문제가 있습니다.

KB_Agent는 사용자의 기본 정보와 생활·재무 정보를 단계적으로 수집한 뒤, 리스크를 분석하고 보장 공백을 시각화하여 적합한 상품을 탐색할 수 있도록 설계했습니다.

단순한 상품 판매가 아니라, 리스크 진단과 상품 추천 과정을 분리하여 사용자가 자신의 상황을 먼저 이해하도록 하는 것을 목표로 했습니다.

## 주요 기능

- 사용자 정보 단계별 수집
- 리스크 프로파일링
- 보장 공백 분석
- 고지의무 확인
- 보험상품 매칭
- 사용자 질문 응답
- 설계 조건 조정
- 최종 보험 설계 리포트 제공
- 리스크 및 보장 결과 시각화

## 서비스 흐름

1. 사용자 정보 수집
2. 리스크 프로파일링
3. 보장 공백 분석
4. 고지의무 확인
5. 보험상품 매칭
6. 질의응답
7. 설계 조건 조정
8. 설계안 확정
9. 최종 리포트 제공

## 기술 스택

- Claude API

- Vercel

## 담당한 역할

- 보험 설계 서비스의 전체 사용자 흐름 기획
- 9단계 대화 흐름 설계
- 사용자 정보 입력 및 결과 화면 등 전반적 UI 구성
- 리스크 맵, 보장 공백, 상품 매칭, 최종 리포트의  시각화 기획
- 생성형 AI 개발 도구를 활용한 MVP 구현
- 시스템 프롬프트와 데이터 구조 정리
- 테스트 및 오류 수정

## 주요 개선 과정

초기에는 보험상품 데이터와 통계 데이터를 시스템 프롬프트에 직접 포함해 프롬프트 크기가 커지는 문제가 있었습니다.

이를 해결하기 위해 원본 JSON 데이터와 시스템 프롬프트를 분리하고, 대화에 필요한 핵심 정보만 요약해 전달하도록 구조를 수정했습니다.

그 결과 기존의 9단계 대화 흐름과 리스크 진단 기능을 유지하면서 프롬프트 크기를 줄일 수 있었습니다.

- 9단계 대화 흐름 설계
- 리스크 및 보장 공백 시각화 화면 구현
- Vercel 배포 환경 구성
- AiNOS X CREAI+IT 산학협력 프로젝트 우수상 수상

## 현재 상태

본 프로젝트는 산학협력 프로젝트에서 제작한 MVP입니다.

보험 리스크 진단, 보장 공백 분석, 상품 매칭 등 주요 서비스 흐름을 구현했으며, 실제 상용 서비스로 활용하기 위해서는 보험상품 데이터 검증, 규제 검토, 보안 강화 및 추가 테스트가 필요합니다.

## 프로젝트를 통해 배운 점

복잡한 산업 문제에 AI를 적용할 때는 모델 자체보다 업무 흐름과 데이터 구조를 먼저 이해해야 한다는 점을 배웠습니다.

또한 사용자의 금융·보험 정보를 다루는 서비스에서는 편리한 기능뿐 아니라 결과의 정확성, 설명 가능성, 규제 준수와 검증 과정이 중요하다는 점을 경험했습니다.
